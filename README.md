# E-Commerce Data Platform

An end-to-end data engineering project built to demonstrate 
database design, SQL analytics, and data pipeline development.

## Overview

A relational database system for an e-commerce platform, 
designed with normalized schema and real business analytics queries.

## Tech Stack

- PostgreSQL
- SQL
- Python (coming soon)
- Docker (coming soon)
- Airflow (coming soon)
- dbt (coming soon)

## Database Schema

Five normalized tables:
- `customers` — customer profiles
- `products` — product catalog
- `orders` — customer orders
- `order_items` — line items per order
- `payments` — payment records

## Analytics Queries

- Total revenue
- Revenue by customer
- Best selling products
- Unpaid orders detection
